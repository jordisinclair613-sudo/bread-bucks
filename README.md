# BREAD BUCKS
A browser business/economy simulator prototype.

## Run
Open `index.html` in a browser, or deploy the folder to Vercel Drop.

## Important
This version is a client-side prototype. Accounts, passwords, companies and balances are stored in the browser's localStorage. It is **not** secure authentication and users on different devices do not share the same marketplace data.

For a real multi-user production version, replace localStorage with a real database/authentication backend and move economy/payout calculations server-side.

Vercel supports dropping a project folder into Vercel Drop, where it can detect framework projects or deploy static files directly.
